Chapter 03 · Notes 6 min read

How the Loop Works

The script uses a timer to move the window down by a few pixels every few milliseconds. Once the window has scrolled past the bottom of the document, it instantly resets to the top and starts scrolling down again.

Because there are no controls, the user cannot change the speed or stop the scroll. That's intentional for this demo: it's a pure auto-scroll loop with a very simple UI.

// pseudo-code
every 16ms:
  scroll down by 1px
  if scrollY >= maxScroll:
    scroll to top
